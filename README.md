# SANDIKALE STORE

Independent storefront MVP for SANDIKALE custom apparel.

## Current build
- Mobile-first industrial premium storefront
- Entrance hero and quick-shopping navigation
- Starter product catalog
- Custom Lab preview concept
- WhatsApp and Instagram contact links
- Reduced-motion support
- No backend credentials, payment processing, or connection to existing KASIR/CLUB systems

## Deploy to Cloudflare Pages (Free)
- Framework preset: None
- Build command: leave empty
- Build output directory: /
- Production branch: main

## Next development stages
1. Product catalog backed by Cloudflare D1
2. Admin authentication and protected dashboard
3. Artwork upload with private object storage and file validation
4. Customization rules and front/back preview
5. Server-side price calculation and order snapshots
6. Order review and manual payment verification
7. QA and later, separately approved KASIR API integration

Do not add KASIR or SANDIKALE CLUB credentials or database connection details to this repository.
